# Ark Solitaire

A web-and-mobile-friendly implementation of Kabufuda Solitaire by Zachtronics, reskinned with animal-themed cards as "Ark Solitaire".

Note that drag-and-drop is not supported or needed. Moves are done by selecting the card or stack, then clicking its destination.

Play here: (ad-supported) [https://www.onlinemathlearning.com/ark-solitaire-game.html]

Or here: [https://spheniscine.github.io/solitaire-ark/]<br>
